## 设置项

```jsonc
{
  "game_dir": "",             // 游戏根目录，留空自动探测（Steam 库 / 常见路径）
  "wkit_path": "",            // WolvenKit.CLI.exe，留空自动探测
  "res_source_lang": "en-us", // 归档里的原文语言
  "res_skip_target": true     // 跳过已是 zh-cn 的文本
}
```

自动探测不需要用户配置：`localization/archive.py` 会遍历 `libraryfolders.vdf`
与常见安装位置；`localization/wkit.py` 会找 `D:\wkit-tools\console-*\`、
`%LOCALAPPDATA%\Programs\WolvenKit\`、`Program Files` 等位置。

## 界面流程

```
「打开 mod 归档」 → 选 .archive.xl / .archive / .zip
      ↓  后端解包 + 抽条目（异步，进度条）
表格填满，行号列变成「条目 ID」
      ↓  翻译（机器翻译 / 手动 / 读入 Excel 都照旧）
「生成翻译 mod」（就是原来的「应用到模组」按钮，资源模式下换文案）
      ↓  组包 + 自动校验
toast 提示产物名，「安装到游戏」按钮出现
      ↓  点击才写游戏目录
archive\pc\mod\<name>.archive + <name>.archive.xl
```

**产物永远先落到输出目录**（`%APPDATA%\2077ModTranslator\output\`），
点「安装到游戏」才拷进游戏。批量跑时不会一次性污染游戏。

### 资源模式下的界面差异

`applyModeUi()` 一处集中处理：

| 元素 | 源码模式 | 资源模式 |
|---|---|---|
| 行号列表头 | 行号 | 条目 ID |
| 应用按钮 | 应用到模组 | 生成翻译 mod |
| 撤销上次应用 | 显示 | 隐藏（没有可撤销的写回） |
| 合并重复行 | 显示 | 隐藏（按主键去重，没有重复概念） |
| 打包为 zip | 按需 | 隐藏 |
| 打开输出目录 / 安装到游戏 | 隐藏 | 显示 |

## 语言筛选策略

多语言 mod（如 EquipmentEx 有 13 种语言、764 条）如果全量展示，用户没法用。

`web_app._filter_l10n_rows()` 的规则：

1. 目标语言（zh-cn）的文本一律去掉——已经翻译过了。
2. 只保留原文语言（默认 en-us）的文本。
3. **若 mod 根本没有原文语言**（例如只发布了 zh-cn 的 `they_will_remember_chs`），
   退回保留其他非目标语言，否则会把唯一可用的文本一起滤掉。

实测 EquipmentEx：764 条 → 66 条（en-us），跳过 698 条，状态栏会说明。

## 无窗口自测

```powershell
python tools\l10n_test.py api "<mod.archive.xl>" --limit 2
```

走 `web_app.Api` 的真实代码路径（`l10n_env` → `_do_load_resource` →
`_apply_resource`），不创建窗口。输出示例：

```
环境: OK
  CLI : D:\wkit-tools\console-9.1.0\WolvenKit.CLI.exe 9.1.0
  游戏: E:\SteamLibrary\...\Cyberpunk 2077
  mode : resource
  行数 : 11
  语言 : {'en-us': 11}
提交 2 条 …
  成功 : 2  失败 : 0
  校验 : 通过
```

前端另有三个静态检查（本机无 node，用便携版）：

```powershell
& D:\wkit-tools\node\node-v22.11.0-win-x64\node.exe --check src\web\app.js
```

以及启动诊断：设置 `MT_STARTUP_LOG=<文件>` 后启动，日志出现
`frontend boot complete` 说明 `bind()` 与 `render()` 都跑完了
（它俩在 `ui_ready()` 之前执行，任何异常都会变成 BOOT ERROR 而不会走到这一步）。

   完全不同（`atomiic_vikki_hair_ccxl.xl` ↔ `Atomiic_Vikki_-_High Ponytail_CCXL.archive`），
