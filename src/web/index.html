资源模式

      

        资源模式：翻译 .archive 内的本地化资源，需要游戏目录与 WolvenKit 命令行。

      

        

      

        

      

        

      
      

        
        
      

      
目录

      

        汉化包输出：点「应用」生成的 zip 放在这个目录，包名固定为 CP2077 Localization Pack.zip。留空则跟着安装缓存目录走。

      

        
        

      

      

      

        批量翻译：产物写到这个目录，原目录只读。留空则不进行批量翻译。

      

        
        

      

      

        Vortex 活动映射：安装缓存目录是工具实际改写的文件（Vortex 用硬链接把它和游戏目录连起来）；下载包目录只读，用来判断装的是哪个版本。

      

        
        

      

        
        

      

        
        
        
      

      
      
语料与缓存

      

        官方双语语料（基线 TM）：把官方语言包按主键对齐，得到游戏自己的 en→zh 译文。它排在机翻记忆之前——命中就直接用，不再发给模型。

      

        
        
      

      
      
      

      

        缓存清理：只删下面这些「用到会重新生成」的目录，翻译记忆、官方语料、设置与术语表都不在里面。
